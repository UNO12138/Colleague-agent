# 生成式 UI：范围与限定

更新日期：2026-09-28。

本文件用于当前原型的设计与接入对齐。以下分别标明已经实现的代码约束、模型表达规则和后续接入要求。文档本身不代表新增能力已经实现，也不代表本轮重新运行了全部测试。

## 一、当前定位

当前能力是「基于阶段原文的受约束生成式预览」。

模型生成阶段 Markdown，再根据其中的内容关系建议版式；服务端检查版式和原文块引用，前端通过固定组件展示。

**真实模型参与生成，不等于真实主进程代理已经执行或核实任务。** 当前阶段输入包含页面文本和模拟步骤的快照，不能据此声称资料已核实、工具已执行或任务已完成。

## 二、生成权限

### 已实现的约束

- 可用版式限定为七种，模型不能添加新的模板类型。
- 布局数据只允许选择模板和已有原文块编号；不存在的编号、重复编号及非整数编号会被过滤。
- 最终界面由前端固定组件渲染。布局模型不能直接注入任意网页结构、样式或可执行脚本。
- 原始 Markdown 与布局结果分别保存，便于回看预览所依据的文本。

### 模型表达规则

- 视觉协作代理只抽取和编排已有信息，不搜索、不改写事实、不补充缺失数据。
- 根据内容的分类、比较、数量、流程或空间关系选择版式。
- 步骤标题只用于显示，不能作为模板判断依据；不能根据产品名称固定套用某种版式。
- 缺失信息不应被编造成占位事实。

上述表达规则写在模型提示中，尚不能等同于服务端已逐条验证其语义正确。

## 三、七种版式及使用条件

| 版式 | 使用条件 | 当前约束情况 |
| --- | --- | --- |
| 摘要 | 单一、连续的结论或叙述，没有明确分类关系 | 分类内容会由服务端从摘要改为卡片 |
| 分类卡片 | 两个以上分类小节，或明确的并列要点 | 服务端识别二级、三级标题及无序要点 |
| 对比矩阵 | 原文存在定性对比表 | 有表格但不满足数字图表条件时使用；无表格时不能使用 |
| 数字图表 | 原文表格具有可解析且单位一致的数字 | 服务端检查数字格式和单位；尚未核实统计口径是否可比 |
| 环形图 | 明确的百分比构成关系 | 当前以两列表格、最多六项、百分比合计接近 100% 判断；尚未核实类别是否互斥 |
| 流程 | 原文明确存在先后、状态变化或因果推进 | 模型提示要求引用支撑节点的原文；服务端尚未验证流程关系 |
| 画布 | 原文明确存在分组、聚类或空间关系 | 模型提示要求引用支撑分组的原文；服务端尚未验证空间关系 |

**分类内容优先使用卡片。摘要不应成为分类叙述的默认回退形式。**

## 四、当前服务端判定顺序

1. 首个表格满足数字解析条件：构成比例使用环形图，其他数字使用图表。
2. 存在表格但不满足上述条件：使用对比矩阵。
3. 没有表格：对比矩阵、图表、环形图会回退为卡片或摘要。
4. 出现两个以上二级或三级标题，或者没有这些标题但有两个以上无序要点：视为分类内容；摘要会改为卡片。
5. 其他情况：采用有效的模型建议；建议缺失或无效时，使用卡片或摘要回退。

这是当前代码的判定顺序。它尚未处理「一段内容同时有多个表格或多种关系，需要组合版式」的完整情况。

## 五、内容与数量限制

以下均为当前代码中的实际限制：

| 对象 | 限定 |
| --- | --- |
| Markdown 解析 | 识别一级至三级标题、段落、无序要点和标准表格；不是完整 Markdown 渲染器 |
| 原文块 | 最多保留前 40 块 |
| 表格 | 每张最多保留前 12 行；版式判断及图表数据使用首个表格 |
| 常规块选择 | 模型建议最多保留 7 个有效、不重复的原文块编号 |
| 分类小节卡片 | 最多展示前三个分类小节；每个小节选取首个段落或要点，并保留一级标题（如有） |
| 并列要点卡片 | 最多展示前六个无序要点，并保留一级标题（如有） |
| 数字图表 | 至少两列、两行；数据值须可解析为非负数字，且单位一致；最终最多展示 10 个数据点 |
| 环形图 | 两列、最多六项、单位为百分比，合计与 100 的差不超过 1 |

因此，**预览可能只展示部分内容，不能替代完整阶段原文**。后续应增加明确的裁剪提示和完整原文入口，避免用户把简化视图当成全部结果。

## 六、执行与交付限定

- 当前步骤推进和阶段生成含有手动演示入口，尚未由真实主进程代理的执行事件自动驱动。
- 阶段草稿、阶段预览和最终交付文件需要分别看待。生成预览不代表最终交付完成。
- 只有服务端实际生成文件并返回路径后，才显示最终交付文件卡。
- 视觉模型失败时可以采用规则回退，并记录回退原因。回退成功只说明预览能够展示，不代表内容正确或版式最佳。
- 本机恢复依赖会话标识、步骤标题及运行文件；更名步骤、删除运行目录或跨设备时，当前不能保证恢复。

## 七、真实接入前需要补齐的要求

以下是接入要求，当前尚未全部实现：

1. **真实事件来源**：主进程代理提供会话、步骤、执行状态、时间、来源和版本，不能用页面模拟文本代替执行证据。
2. **证据映射**：阶段原文和预览块能够追溯到工具结果、文件或其他证据，并区分事实、推断和待核实内容。
3. **关系校验**：核实图表的统计口径、环形图的构成关系，以及流程、画布中的实际关系。
4. **版本与失败状态**：区分生成中、生成失败、草稿、已审阅和最终交付；明确重生成是否保留历史。
5. **截断提示**：超出数量限制时告知用户预览被简化，提供完整原文入口。

## 八、验收口径

- 分类内容没有被错误压成摘要。
- 无表格时不生成对比矩阵；非数值表格不强行转为图表。
- 混合单位数据不进入当前数字图表；构成条件不满足时不使用环形图。
- 预览不补充原文不存在的事实、数字或执行结果。
- 失败回退可识别，真实文件状态可核对。
- 涉及裁剪、证据与真实执行时，按尚未实现的能力列出缺口，不能只凭测试通过宣称完整闭环完成。
